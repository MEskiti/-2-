1. Словник англійських термінів (English Glossary)
(Необхідно для отримання додаткового бала)

Kernel – ядро операційної системи, центральна частина ОС, яка керує апаратним забезпеченням та ресурсами.

Filesystem Hierarchy Standard (FHS) – стандарт ієрархії файлової системи, що визначає структуру каталогу та розташування файлів у дистрибутивах Linux.

Pseudo Filesystem – псевдо файлова система; віртуальна файлова система, яка не займає місця на диску, а існує лише в оперативній пам'яті для надання інформації про стан ядра та процесів (наприклад, /proc, /sys).

Virtual Addressing – віртуальна адресація; метод управління пам'яттю, що дозволяє процесам спільно використовувати фізичну пам'ять без конфліктів.

Log Files – файли журналів (логів); файли, у які система та сервіси записують повідомлення про свою роботу для діагностики та аудиту.

Log Rotation – ротація логів; процес регулярного архівування, перейменування та очищення старих лог-файлів для економії простору.

Host – хост; будь-який пристрій (комп'ютер, телефон, сервер), підключений до мережі та здатний до комунікації.

Router / Gateway – маршрутизатор (шлюз); пристрій, що з'єднує різні мережі та перенаправляє між ними пакетні дані.

Subnet Mask (Netmask) - маска підмережі; числова система, що визначає, які IP-адреси належать до однієї локальної мережі.

DHCP (Dynamic Host Configuration Protocol) - протокол динамічного налаштування хостів, що автоматично призначає IP-адреси та параметри мережі.

DNS (Domain Name System) - система доменних імен, призначена для трансляції текстових доменних імен у числові IP-адреси.

NAT (Network Address Translation) - трансляція мережевих адрес; технологія, що дозволяє багатьом пристроям приватної мережі виходити в інтернет через одну загальну IP-адресу

2.1. Розкрийте поняття “псевдо файлової системи”, для чого воно потрібно системі?
Псевдо файлова система - це віртуальна файлова система, яка не зберігається на фізичному диску, а створюється динамічно операційною системою в оперативній пам'яті (RAM). Вона використовується ядром Linux як зручний інтерфейс для взаємодії між користувачем (або програмами) та ядром системи. Через неї можна отримувати параметри апаратного забезпечення, інформацію про процеси та конфігурацію ядра в реальному часі за допомогою звичайних файлових команд (cat, ls).

2.2. Чому користувачі не так часто звертаються напряму до каталогу /proc, яким чином з нього можна отримати інформацію?
Користувачі та адміністратори рідко звертаються до каталогу /proc напряму, оскільки він містить величезну кількість специфічних файлів і каталогів з «сирими» та неструктурованими даними, які важко аналізувати вручну.
Замість цього використовують спеціальні системні утиліти, які зчитують дані з /proc та форматують їх у зручному для читання вигляді

2.3. Яке призначення файлів /proc/cmdline, /proc/meminfo та /proc/modules?
/proc/cmdline - містить параметри та спеціальні інструкції, які були передані ядру операційної системи під час його первинного завантаження (бутстрапу).
/proc/meminfo - надає детальну статистику про використання оперативної пам'яті (RAM) та простору підкачки (Swap) ядром системи.
/proc/modules - містить список модулів, які наразі завантажені в ядро для розширення його функціональності (наприклад, драйвери пристроїв).

2.4. Яке призначення команди free?
Команда free призначена для виведення миттєвого знімка (snapshot) стану використання оперативної пам'яті та простору Swap у системі (загальний об'єм, використано, вільно, буфери/кеш). За допомогою опції -s <секунди> її можна використовувати для моніторингу пам'яті в режимі реального часу з заданим інтервалом

2.5. Для чого потрібні лог-файли, наведіть приклади їх застосування?
Лог-файли (журнали) - це файли, куди ядро, демони та інші процеси записують системні події, попередження та помилки. Вони необхідні для:
Усунення несправностей (Troubleshooting): Допомагають швидко знайти причину збою в роботі сервісів або обладнання.
Безпеки та аудиту: Виявлення спроб несанкціонованого доступу до системи (наприклад, через журнали авторизації /var/log/secure або /var/log/auth.log).
2.6. Яке призначення файлу /var/log/dmesg?
Файл /var/log/dmesg містить повідомлення, які генеруються ядром операційної системи під час процесу завантаження (boot-up) пристроїв та ініціалізації обладнання.
2.7. Для чого розроблено FHS?
Filesystem Hierarchy Standard (FHS) — це стандарт ієрархії файлової системи, який встановлює чіткі правила та рекомендації щодо того, де і які файли та каталоги повинні розташовуватися в дистрибутивах Linux. Це забезпечує сумісність програмного забезпечення та передбачуваність структури для адміністраторів у різних дистрибутивах.
2.8. Які основні команди є у Linux для перегляду та конфігурації мережі?
ifconfig — класична команда для перегляду та налаштування мережевих інтерфейсів (застаріває в нових дистрибутивах)
ip (наприклад, ip addr show) — сучасна універсальна заміна ifconfig для повноцінного керування мережею та маршрутизацією\
ping — перевірка доступності хоста в мережі за допомогою ICMP-пакетів.
netstat / ss — перегляд мережевих з'єднань, відкритих портів та статистики сокетів.
route — перегляд та редагування таблиці маршрутизації.
dig / host — виконання DNS-запитів для визначення IP-адрес за доменним ім'ям.
